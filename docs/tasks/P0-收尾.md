## 【验收标准】

### 步骤 1 · 装依赖

```bash
cd backend && uv sync --extra dev
```

```bash
cd frontend && npm install
```

### 步骤 2 · 后端门禁（六道，必须全绿）

```bash
cd backend && uv run ruff format --check . && uv run ruff check . && uv run pyright && uv run lint-imports && uv run pytest -q && uv run python -m app.scripts.check_contract
```

### 步骤 3 · 起服务

```bash
cd backend && cp .env.example .env && uv run uvicorn app.main:app --reload --port 8000
```

打开 http://localhost:8000/docs —— **能看到全部接口**，这是蓝图 P0 验收的一条。

### 步骤 4 · 起前端并亲手点

```bash
cd frontend && npm run dev
```

打开 http://localhost:5173 ：

- [ ] 用 `.env` 里的账号（`admin@example.com` / `admin12345`）能登录
- [ ] 刷新页面后仍是登录状态
- [ ] 看到模型下拉框，默认选中 **Mock 模型**
- [ ] 输入一句话发送，回答**逐字**出现（不是整段一次蹦出来）
- [ ] 回答下方显示上游模型与费用
- [ ] 点"退出"能登出

**这是 P0 的核心验收**：蓝图第 11 节 P0 那一条。

### 步骤 5 · 生成真实类型

```bash
cd frontend && npm run gen:api && npm run typecheck && npm run lint
```

`src/api/schema.d.ts` 目前是**手写占位文件**，这步会覆盖成 OpenAPI 生成的真实类型。

### 步骤 6 · 沙箱验证（需先装 Docker）

```bash
cd sandbox && docker build -f Dockerfile.base -t workbench-sandbox-base:latest . && docker build -f Dockerfile.ocr -t workbench-sandbox-ocr:latest . && ./verify-ocr.sh
```

要看到三件事：Git 版本 ≥2.41、**容器内访问外网失败**（这一步必须失败才算通过）、
`ocr review --preview` 成功列出待审文件。
