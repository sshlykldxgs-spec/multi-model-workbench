# ADR-0004：预览功能不进核心路径

- 状态：已采纳
- 日期：2026-10-14
- 来源：蓝图 1.0 第 4 节、第 12 节第 10 项

## 背景

MAF 的 DevUI、AG-UI、托管集成、Skills 仍是预览功能，API 可能变动。

## 决策

预览功能一律不进核心路径。具体：

- 前后端协议用**自研 REST + SSE 契约**，不用 AG-UI + CopilotKit。
- 模型接入不依赖 MAF 的连接器作为唯一路径（见 ADR-0003）。
- 产品内置技能系统**自研 `SkillLoader` 接口**，MAF Skills 作可选实现（见 `design.md` 6A）。
- 全部依赖锁定版本；MAF 升级单独提交，跑完回归用例再合并。

## 理由

核心路径的稳定性优先于功能丰富度。预览功能的变动不应导致产品不可用。

## 后果

- 需要自己维护契约与部分能力，短期成本更高。
- 换来升级安全与可测试性，符合蓝图选型原则。
