# ADR-0002：自研消息表是历史的唯一事实来源

- 状态：已采纳
- 日期：2026-10-14
- 来源：蓝图 1.0 第 5.3 节

## 背景

产品要求在同一会话中**中途切换模型**。MAF 序列化的会话能否跨厂商复用未经证实。

## 决策

自研 `messages` 表是历史的唯一事实来源。每次运行时，把中性格式历史**重建**为 MAF 上下文。

## 理由

- 中途切换模型需要中性格式的历史，不能绑定任一厂商的消息结构。
- 不依赖未经证实的跨厂商序列化能力，降低框架耦合。

## 后果

- 每次运行有重建上下文的开销（可接受，相对模型调用延迟可忽略）。
- 裁剪与摘要逻辑由我们掌控，见 `design.md` 第 4 节。
- 裁剪必须以完整消息为单位，不得切断工具调用与其结果的配对。
