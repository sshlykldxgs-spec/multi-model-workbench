# ADR-0003：模型接入按协议划分，支持官方与中转双线

- 状态：已采纳
- 日期：2026-10-14
- 来源：用户第二轮补充意见第 2 点

## 背景

用户要求**所有模型接入均需支持中转站**。中转站绝大多数只实现 OpenAI 兼容协议，
不区分厂商；且实际能力常少于官方（可能不支持工具调用、流式，或看不到真实上下文长度）。

## 决策

- `ModelGateway` 内部按**协议**而非厂商划分适配器：
  `openai_compat` / `anthropic` / `gemini`。
- 模型条目级配置 `base_url`、`credential_ref`、`protocol`、`provider_label`、单价与路由。
- 能力标记自动探测只作**建议值**，管理员可手动覆盖（A-17）。
- 降级（官方→中转）必须在事件流中告知用户，不得静默换模型（A-18）。
- **一切模型调用必经 `ModelGateway`**，任何模块不得直接 import 厂商 SDK。

## 理由

新增一个中转站通常只是加一行配置。字节数据也不因厂商差异而进入业务逻辑。

## 后果

- MAF 自带的连接器降级为 `ProviderAdapter` 的**可选实现**，而非唯一接入路径（偏差 D-3）。
- 需要维护能力标记的覆盖机制与运行前校验。
- 计量必须记录**上游真实模型名**与**条目单价**，因为中转站可能返回不同的 model 字段与价格。
